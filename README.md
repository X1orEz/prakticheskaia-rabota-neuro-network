## 🧠 Архитектура нейронной сети (CNN)

Модель разработана **с нуля** на TensorFlow/Keras без использования предобученных весов (Transfer Learning). Это позволило глубже понять влияние каждого слоя на процесс обучения.

**Входной тензор:** `(200, 200, 3)` — RGB-изображения, приведённые к единому разрешению.

### Структура сети:

1.  **Блоки свертки (Convolutional Blocks):**  
    Архитектура состоит из 5 последовательных блоков. Каждый блок включает:
    - `Conv2D` с ядром 3×3 и нарастающим числом фильтров (128 → 256 → 512 → 512 → 1024).
    - `BatchNormalization` — для стабилизации обучения и ускорения сходимости.
    - `Activation('relu')` — нелинейность.
    - `MaxPooling2D(2,2)` — уменьшение размерности карт признаков вдвое.
    - `Dropout(0.25)` — регуляризация для борьбы с переобучением (только в первом блоке).

2.  **Переход к полносвязной части:**
    - `GlobalAveragePooling2D()` — заменяет традиционный `Flatten`, что **значительно сокращает число параметров** (примерно в 4 раза) и дополнительно защищает от переобучения.

3.  **Классификатор:**
    - `Dense(1024, activation='swish')` — полносвязный слой с современной функцией активации Swish, которая часто показывает себя лучше ReLU на глубоких архитектурах.
    - `Dropout(0.3)` — регуляризация.
    - **Выходной слой:** `Dense(75, activation='softmax')` — распределение вероятностей по 75 видам бабочек.

**Итоговое количество параметров:** 9,694,539
